- **`window::set_enabled` and parent centring (#104, #35 slice 2)** — adds `window::set_enabled(id, bool)` (native on Windows, a runtime input filter everywhere; a disabled window keeps drawing and lifecycle events, drops keyboard, mouse, touch, IME and file-drop input, and sees no cursor), focus redirect to the owned dialog, and `window::parent_supported()` (Windows and macOS). On Windows a natively disabled window gets no `CloseRequested` from its caption button or Alt+F4, so the last enabled window is only disabled for the filter, never natively, with a warning. **Behaviour change:** `Position::Centered` with `parent: Some(..)` now centres on the parent window, clamped to its monitor, instead of on the monitor. **Behaviour change:** plain `Position::Centered` now really centres when the program `scale_factor` is not 1.0 (it used the unscaled size). **Behaviour change:** a close that leaves only disabled windows enables them again after the application handled `Closed`, with a warning. **Breaking:** `runtime::window::Action` gains `SetEnabled`, so an exhaustive match stops compiling. Signex: its modal dialogs can disable the owner and open centred on it; on X11 and Wayland keep an in-window lock, because the filter eats every key on a disabled window.
