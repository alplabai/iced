- **Title bar caption regions on Linux and macOS (#129)** — a press in a `TitleBarRegion::Caption` region now drags the window, a double click toggles maximization and a right click opens the window menu on Linux, the BSDs and macOS, as the native caption does on Windows 11; a `Maximize` region keeps its button's clicks. Apps that already wrapped a strip for Windows get this behaviour there too, whatever their decorations. Web, Android and iOS are unchanged. Signex: one title strip code path for every desktop platform.
