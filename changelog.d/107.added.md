- **Windows: extend content into the title bar (#107, #105)** — `window::settings::PlatformSpecific` (Windows) gains `extend_content_into_title_bar: bool` (default `false`), which makes the client area cover the caption while the window keeps its native resize borders, shadow and rounded corners; `window::drag` still works. Only effective with `decorations: true`; the app draws its own caption buttons. Windows 11 is the primary target. **Breaking:** the Windows `PlatformSpecific` struct gains a field, so exhaustive literals stop compiling. Signex: a custom title bar on Windows with native borders.
