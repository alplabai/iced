- **Behaviour change: Windows apps no longer use Vulkan by default (#110)** — the wgpu renderer now defaults to DX12 then GL on Windows (`backend::Api::Best`, `compositor::Settings::default` and the headless renderer); other platforms are unchanged. `WGPU_BACKEND=vulkan` or an explicit `backend::Api::Vulkan` still selects Vulkan. Signex: opens on machines whose Vulkan driver is broken, such as an Intel UHD 630 laptop whose driver crashes in `vkCreateDevice`; set `WGPU_BACKEND=vulkan` to opt back in.
