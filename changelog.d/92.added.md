- **SVG `currentColor` from the text color (#92, upstream #3434)** — `svg(..).style(svg::current_color)`, or `inherit_current_color: true` in `svg::Style`, paints an icon's `currentColor` with the parent's text color, so an icon next to a label follows the theme without flattening its other colors. Translucent colors keep their alpha. **Breaking:** new public fields `svg::Style::inherit_current_color` and `core::svg::Svg::current_color`, so struct literals need them or `..Default::default()`. Signex: its ~14 `svg::Style { color: .. }` literals need `..Default::default()`; icons drawn with `currentColor` can then follow the theme text color instead of a flat `color` tint.
