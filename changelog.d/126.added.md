- **Windows 11: native caption and maximize regions in an app-drawn title bar (#105)** — in a window with `extend_content_into_title_bar`, wrapping part of the title strip in `widget::title_bar_region(window::TitleBarRegion::Caption, ..)` makes it the native caption: dragging moves and snaps the window, double-clicking maximizes it and right-clicking opens the system menu. Wrapping the app's maximize button in `TitleBarRegion::Maximize` shows the Snap Layouts flyout on hover while the button keeps its clicks. The regions are suspended while an overlay is open. **Breaking:** `runtime::user_interface::State::Updated` gains a `title_bar` field. Windows 10 is not supported. Signex: the main window can switch from `decorations: false` plus `window::drag` to the native frame with caption regions once it pins this; no Signex code path uses it yet.
